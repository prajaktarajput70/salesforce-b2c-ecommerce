# Salesforce B2C E-Commerce Management Application

## Overview
A Salesforce-based e-commerce application for product
catalog, cart, checkout, order processing and inventory management.

## Technologies
- Salesforce
- Apex
- SOQL
- Lightning Web Components (LWC)
- Static Resources

## Features
- Product Catalog
- Shopping Cart
- Checkout and Order Creation
- Inventory Management
- Shipment Processing

## Project Structure
- classes: Apex classes
- lwc: Lightning Web Components
- staticresources: Static resources
- objects: Object and field metadata
